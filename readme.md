#  Sunu-Idées

## Présentation

Sunu-Idées est une application web de boîte à idées collaborative permettant aux utilisateurs de proposer, consulter, modifier et supprimer des idées de manière simple et intuitive.

L'objectif est de favoriser le partage d'idées au sein d'une communauté, d'une promotion ou d'une organisation grâce à une interface inspirée des tableaux collaboratifs modernes.

---

## Fonctionnalités

### Create

* Ajouter une nouvelle idée
* Saisir un titre
* Choisir une catégorie
* Ajouter une description

### Read

* Afficher les idées sous forme de cartes
* Visualiser la catégorie grâce à un badge coloré

### Update

* Modifier le titre ou la description d'une idée via une fenêtre modale

### Delete

* Supprimer une idée du tableau

### Stockage local

* Les idées sont enregistrées dans le Local Storage du navigateur
* Les données restent disponibles après rechargement de la page

## Installation

1. Cloner le dépôt :

```bash

```

2. Ouvrir le projet :

```bash
cd sunu-idees
```

3. Lancer `index.html` dans un navigateur.
